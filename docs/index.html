PacBio Single-molecule real-time (SMRT)

  • Library preparation
    • Formation of a SMRTbell as template
      • Closed single stranded circular DNA
      • This is achieved by ligating hairpin adaptors to both ends of the target dsDNA
  • The SMRTbell is loaded onto chip and diffuses into one of many sequencing units, called a zero-mode waveguide (ZMW)
    • The smallest available volume for light detection, removing background
  • Each one of these ZMWs have a DNA polymerase immobilized at the bottom
    • This polymerase can then bind to either of the hairpins
    • Fluorescent labeled nucleotides are provided to the ZMW and thus the enzyme
      • Each of the 4 nucleotides are labeled with fluorophores emitting different wavelengths
        • Allows differentiation
      • Flourophores are covalently attached on the γ-phosphate
  • On each incorporation of a labeled dNTP, a light pulse is produced
  • Along with the the ZMW a camera can record these light flashes and the sequences is deduced
  • A single pass results in a sequence accuracy of 11-15%
    • However, since the template is circular, multiple passes is possible
      • Due to the randomness of error an accuracy rate of ~99.9% is possible
      • Sequencing and passes are possible until the enzyme stops working or for the duration of the enzymes lifetime
      • There is a trade of between sequence accuracy and read length

Oxford Nanopore Technologies

The ONT principle

  • Biological pores or transporters are embedded in a semiconductor chip
    • As particles pass through this chip the resistance over the membrane changes
  • dsDNA or RNA is mixed with a motor protein which binds these molecules to the pores
  • The DNA or RNA is threaded through the pores and the changes in current is recorded
  • This wave pattern is used to infer the sequence
  • Very long read lengths
  • Can detect epigenetics
  • They promise protein sequencing
    • Multi-omics

Phred / Q-scores

Developed by Phil Green and Brent Ewing, 1990s

\[ Q=−10.log_{10}(p) \qquad(1)\]

or

Q10 = 90%         (1/10 chance of an incorrect base call)
Q20 = 99%         (1/100 chance of an incorrect base call)
Q30 = 99.9%       (1/1,000 chance of an incorrect base call)
Q40 = 99.99%      (1/10,000 chance of an incorrect base call)
Q50 = 99.999%     (1/100,000 chance of an incorrect base call)
Q60 = 99.9999%    (1/1,000,000 chance of an incorrect base call)
These have been adopted by NGS technologies and is encoded in the FASTQ files
